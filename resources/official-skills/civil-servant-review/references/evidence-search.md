# 真实参照：联网检索与引用

AIThink Agent 当前无独立 WebSearch，用 **Bash + curl** 访问公开页。目标是给结论补「机关名称 / 公开案例」，不是爬取内网。

## 何时必须检索

- 准备下「会遇到」且依据偏弱时
- 用户明确要求「真实机关或案例」
- 「不会遇到」需要对比「机关里实际对应什么活」且本地对照不够时

可跳过检索：明显企业主线话术（投标/融资/客户拜访当公务员主业）——直接判否，并给机关侧对应工作。

## 优先来源

1. `*.gov.cn` 政府网站：机构职能、「三定」公开、信息公开、工作动态
2. 地方投促 / 发改 / 商务 / 政务公开栏目
3. 中央或地方公开的公文处理、信息公开相关规范页

避免：自媒体转述当唯一依据；无法打开的链接假装已核实。

## 检索词模板

按场景选用，可替换地名：

```text
投资促进中心 机构职能
投资促进 工作简报 OR 要情
招商引资 调度 会议
办公室 会议纪要
调研报告 报送 区县
统计 报表 汇总 填报说明
党政机关公文处理 起草 审核 签发
政府信息公开 目录
```

反例：不要把「企业投标文件编制」「融资商业计划书」搜成机关主责。

## Bash 示例

```bash
curl -sL --max-time 20 "https://www.gov.cn/" | head -c 2000
```

对具体结果页同样 `curl -sL --max-time 20 '<url>'`，从 HTML 中提炼机构名与职能表述；不要把整页 HTML 贴进对用户回复。

## 引用格式（写入报告「真实参照」）

```markdown
- 机关/案例：××市投资促进中心（综合/信息相关公开职能）
- 对应关系：与「公开政策要情摘编」同类，属信息汇集而非审批办结
- 来源：https://... 或《…公开制度名称》；失败则写「未联网核实」
```

## 失败处理

- curl 超时、非 gov 域名不可信、内容无关 → 标注「未联网核实，依据强度：弱」
- 不得编造 URL，不得虚构「某局内部红头文件号」
- 涉密/内部流程只写到「通常需人工核签」一层
