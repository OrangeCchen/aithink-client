# 公务员真实办公对照库

下结论时尽量点名本表类别，并尽量升级为具名机关参照（见 `evidence-search.md`）。

## 较常会遇到（正面锚点）

| 类别 | 典型样子 | 常见岗位 |
|---|---|---|
| 公开政策/要情摘编 | 按主题筛选公开动态，整理重点与来源 | 综合、投促信息岗、办公室 |
| 会议转写与纪要初稿 | 录音/记录 → 纪要结构 + 待办草稿 | 文秘、综合、业务承办人 |
| 调研材料归纳 | 多份问卷/区县材料 → 共性问题与数据表 | 业务处、投促项目岗 |
| 多表汇总与缺项标记 | 下级上报表合并、缺字段/异常提示 | 综合统计、业务汇总岗 |
| 公文/汇报材料初稿 | 基于已有材料起草，供人工修改 | 承办人、文秘 |
| 材料格式与数据一致性校核 | 错字、口径、前后数据不一致提示 | 核稿相关人员 |
| 授权范围内本地资料检索 | 在用户给定目录/知识库中查找引用 | 各业务岗位 |

## 偶发或岗位限定

| 类别 | 说明 |
|---|---|
| 跨区县口径争议处理 | 真实，但常需人工核对，不能当「一键出最终数」 |
| 专项督办闭环 | 有督查职责的岗位才主责；需人工确认节点 |
| 密级件处理 | 真实红线场景；AI 话术须强调授权与人工 |
| 对外正式发文 | 必经审核签发；AI 最多到初稿 |
| 跨系统流程编排 | 多为偶发/项目制，不是每人每天 |

## 通常不是公务员日常主线（易政企混用）

| 类别 | 为何不像机关日常 |
|---|---|
| 企业投标响应材料 | 企业侧商务行为，不是机关公务员主责 |
| 融资材料 / ESG 鉴证结论 | 企业或专业机构场景 |
| 客户拜访日报 | 销售话术，非机关办文办会办事 |
| 替代领导签发 / 直接 OA 办结 | 越过核稿签发链条 |
| 无授权全盘扫描电脑 | 违反机关常见安全与授权习惯 |
| 把内部件当公开网页自动抓取 | 触碰公开/内部边界 |

## 机关类型提示（检索用，勿写死过时个案）

- 地方「投资促进中心/局」综合与项目服务 → 要情、项目调度、区县材料汇总
- 党委/政府「办公室」文秘 → 办文核稿、会议纪要初稿
- 发改/商务等业务处室 → 调研、报表、专项材料
- 不要把机关采购、财务或企业投标融资话术，伪装成通用公务员日常
