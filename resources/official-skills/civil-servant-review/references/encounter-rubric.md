# 遭遇判定六问与结论规则

对每个场景单元逐项作答；材料未写清的标「未写清」，不要脑补成事实。

## 六问

1. **谁在做**：哪个岗位/处室会接手？（综合科、业务处、投促/招商、文秘、督查、办公室等）
2. **为什么现在做**：触发源是什么？（领导交办、例会、上级通知、定期报送、来文来电、专项督办）
3. **手里已有什么**：真实输入是什么？（Word/Excel、录音、OA 待办、纸质扫描、口头交代、授权目录内本地材料）
4. **要交出什么**：产出给谁用？（报送上级、呈领导、处室留存、对外发文、内部协调）
5. **中间有没有人**：是否必须核稿、签发、会签、口径确认？AI 只能辅助到哪一步？
6. **机关禁区**：密级、公开/内部、外网检索、跨部门系统、盖章审批是否被脚本绕开？

## 结论规则

| 结论 | 条件 |
|---|---|
| **会遇到** | 六问 1–4 都能在真实机关找到对应，且有真实参照（机关/案例/规范）支撑；5–6 未被脚本否定 |
| **偶发会遇到** | 工作真实存在，但被写成「全员每天自动完成」或跨处室闭环；须写清岗位与频次边界 |
| **不会遇到 / 不像机关** | 缺触发源与接收对象；跳过审签当常态；或以企业投标/融资/客户拜访等当公务员主线 |
| **信息不足** | 岗位与用途都未写清，无法判断——先 AskUserQuestion，再判定 |

## 依据强度

- **强**：具名机关 + 公开职责/制度/案例 URL
- **中**：法规/规范锚点或公开职能类型（如「地方投促中心综合岗」）
- **弱**：仅对照库类别 + 「未联网核实」

判「会遇到」时尽量达到中或强；只有弱依据时，措辞要保守（「较符合常见机关工作，待公开职能核验」）。

## 常见误判纠正

- Demo 理想路径 ≠ 日常常态（有兜底演示可以，但不能暗示机关天天零摩擦自动办结）
- 「本地文件夹汇总」≠「OA 流程办结」
- 「生成纪要待办」可以；「自动指派并闭环督办」默认需人工确认 → 多为偶发/需改口
- 「公开渠道要情」可以；「内部件自动上网抓」→ 禁区失败
