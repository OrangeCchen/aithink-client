# 能力分流速查

访谈时对每个步骤快速归类：

## A. 纯认知

- 摘要、分类、打分、写邮件草稿、对照检查清单
- 不需要调用外部系统写回

## B. 现有工具可跑

- 读本地文件 / 工作目录
- 浏览器只读或扩展已同步的足迹
- 语音转写结果作为输入

在 skill 里写明「需要什么输入文件/上下文」，不要写未接通的系统名装作已接通。

## C. 缺工具

常见缺口：飞书/企微审批、ERP 库存、CRM 写回、工单状态变更、发真实邮件。

工具缺口卡模板：

```text
系统：
操作：读 / 写
鉴权：
验收用例：
未接前降级：仅生成待提交内容 / 导出表格 / 人工粘贴
```

## D. 必须人工

- 盖章、合同最终签署、放款审批、当面谈判承诺
- skill 中写成「停住并请用户确认」，禁止代劳
